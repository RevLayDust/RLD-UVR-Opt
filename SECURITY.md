# Security Policy

## Supported Versions

Security updates are provided for the latest minor releases of **RLD UVR-Opt**:

| Version | Supported |
| :--- | :--- |
| `v0.2.x` | :white_check_mark: Supported |
| `< v0.2.0` | :x: End of Life |

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project (e.g., untrusted model deserialization, arbitrary code execution via pickled weights, or installer path injection):

1. **Do Not Open a Public Issue**: Do not report security vulnerabilities via public GitHub Issues or discussions.
2. **Private Disclosure**: Report the vulnerability directly to the project maintainers via GitHub Private Vulnerability Reporting or by contacting [RevLayDust](https://github.com/RevLayDust).
3. **Information to Include**:
   - Description of the vulnerability and its potential impact.
   - Minimal reproduction script or steps.
   - Affected Execution Providers, components, or OS versions.

Maintainers will acknowledge receipt within 48 hours and work on a coordinated fix and patch release.
